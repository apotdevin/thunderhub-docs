# Lightning Terminal (litd)

[Lightning Terminal (litd)](https://github.com/lightninglabs/lightning-terminal) is an all-in-one daemon by Lightning Labs that bundles LND, Loop, Pool, Faraday, and Taproot Assets (`tapd`) into a single process. ThunderHub supports litd as a backend, connecting to its LND gRPC endpoint to provide full node management along with Taproot Assets support.

<Callout type="info">
  ThunderHub connects to LND's gRPC endpoint (default port `10009`), the same
  way it connects to a standalone LND node. The additional litd services (Loop,
  Pool, Taproot Assets) are available through the litd UI at
  `https://your-node:8443`.
</Callout>

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) installed (for running ThunderHub)
- A running litd or LND node (mainnet or testnet), or follow the [Developer Environment](/litd/developer-environment) guide to create one locally
